# 完成报告输出模板

规格说明书生成完成后，输出以下格式的报告：

```
## 规格说明书生成报告

- 项目: {项目名称}
- 算子: {算子名称}
- 编程模式 (CC-2): {Developer / Expert / 混合}
- 计算类型 (CC-1): {纯 Vector / 纯 Cube / 混合}
- 输出路径: examples/{项目名称}/{算子名称}/SPEC.md

### 契约条款清单
- IC (接口契约): {N} 条
- FC (功能契约): {N} 条
- AC (验收契约): {N} 条
- CC (约束契约): {N} 条
- ID (实现设计): {N} 条
- RR (风险登记): {N} 条
- DC (交付清单): {N} 条

### 契约自检结果
1. 接口契约 IC 完备: ✅ / ❌
2. 功能契约 FC 完备: ✅ / ❌
3. 验收契约 AC 可验证且可追溯: ✅ / ❌
4. 约束契约 CC 完备 (含技术约束检测): ✅ / ❌
5. 实现设计 ID 具体 (API 到函数名+参数): ✅ / ❌
6. 本项目同类实现列出: ✅ / ❌
7. 参考实现差异说明: ✅ / ❌ / N/A
8. 非整除处理策略 (ID-3): ✅ / ❌ / N/A

### 待确认项
- {列出需要用户进一步确认的内容（不得为 IC/FC/AC/CC 权威契约的必需条款）}
```
