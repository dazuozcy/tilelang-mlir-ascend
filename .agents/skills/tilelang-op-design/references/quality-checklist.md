# 契约质量自检清单

生成 `SPEC.md` 后，按契约类别逐项检查。每条契约须完备、一致、可验证，且带唯一条款 ID。

## 接口契约 IC（权威，必须）

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| IC-1 | 算子名称明确 | ✅ 必须 |
| IC-2 | 输入张量 shape + dtype + 动态轴完整 | ✅ 必须 |
| IC-3 | 输出张量 shape + dtype 完整（迁移类标注原输出 shape） | ✅ 必须 |
| IC-4 | JIT 配置（out_idx、target）明确 | ✅ 必须 |
| IC-5 | Kernel 入口签名完整（`@T.prim_func` 签名） | ✅ 必须 |

## 功能契约 FC（权威，必须）

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| FC-1 | 数学公式明确（非"使用相关公式"） | ✅ 必须 |
| FC-2 | 算法分解到子表达式（多步算子） | ✅ 必须 |
| FC-3 | 数据流图完整 | ✅ 必须 |

## 验收契约 AC（权威，必须可验证且可追溯）

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| AC-1 | 精度标准按 dtype 给出 atol/rtol | ✅ 必须 |
| AC-2 | L0 测试契约（规则 shape、dtype、通过标准） | ✅ 必须 |
| AC-3 | L1 测试契约（非整除/中等规模） | ✅ 必须 |
| AC-4 | L2 测试契约（异常/极小，告警不阻塞） | ✅ 必须 |
| AC-5 | Boundary 测试契约（特殊值） | ✅ 必须 |
| AC-6 | Golden 参考实现完整（PyTorch CPU 可独立运行） | ✅ 必须 |
| AC-* | 每条 AC 可被 Stage 3 测试逐条执行与追溯 | ✅ 必须 |

## 约束契约 CC（权威，必须）

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| CC-1 | 计算类型明确（Vector/Cube/混合） | ✅ 必须 |
| CC-2 | 编程模式有明确结论和理由（非"视情况而定"） | ✅ 必须 |
| CC-3 | NPU 硬件约束（分形/对齐/容量）已核算 | ✅ 必须 |
| CC-4 | 技术约束检测结论（三维 Kernel / GPU API / GEMM 非整除 / L0C 溢出） | ✅ 必须 |
| CC-5 | 内存预算核算（UB 总和 ≤ 容量；Cube 类 L0C ≤ 128KB） | ✅ 必须 |

## 实现设计 ID（推荐）

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| ID-1 | API 映射具体到函数名和参数（非"使用相关 API"） | ✅ 必须 |
| ID-2 | 内存搬运路径完整（GM → 计算 → GM 每一步） | ✅ 必须 |
| ID-3 | Tiling 策略有约束分析（解释 Block/Tile 大小选择） | ⭕ 推荐 |
| ID-3 | 含 GEMM 场景非整除处理策略明确（padding+crop 或动态 block） | ✅ 必须 |
| ID-4 | 循环结构明确（T.Parallel / T.serial / T.Pipelined / T.Persistent） | ⭕ 推荐 |
| ID-5 | 同步策略与 CC-2 编程模式匹配 | ⭕ 推荐 |
| ID-6 | 混合算子 CV 融合设计（纯 Vector/Cube 填不适用） | ⭕ 推荐 |

## 风险登记 RR / 交付清单 DC（参考）

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| RR | 已知约束、常见错误、特殊场景列出 | ⭕ 推荐 |
| DC | 目录结构、文件清单、命名、实现顺序 | ⭕ 推荐 |

## 通用质量

| # | 检查项 | 是否必须通过 |
|---|--------|-------------|
| G-1 | 无占位符或模糊描述（无 `{placeholder}`、TODO、「待补充」，已确认的除外） | ✅ 必须 |
| G-2 | 每条契约带唯一条款 ID，无遗漏 | ✅ 必须 |
| G-3 | 本项目同类实现已列出（具体 examples/ 文件路径） | ✅ 必须 |
| G-4 | 含 GEMM 场景 Tiling 满足 NPU 分形限制（block_M ≥ 16, block_N ≥ 16） | ✅ 必须 |
| G-5 | 含 GEMM 场景 L0C 容量验证（`block_M × block_N × sizeof(accum) ≤ 128KB`） | ⭕ 推荐 |
| G-6 | 参考实现差异已说明（API/结构差异，迁移类必填） | ⭕ 推荐 |
| G-7 | 参考实现标注原算子路径与输出形状（迁移类必填） | ⭕ 推荐 |
| G-8 | 函数无全局变量依赖（维度从 tensor shape 或函数参数获取） | ⭕ 推荐 |
| G-9 | 内部一致：IC/FC/AC/CC/ID 间无矛盾 | ✅ 必须 |

**通过条件**：所有 ✅ 必须项全部通过；⭕ 推荐项至少通过一半。权威契约（IC/FC/AC/CC）的必需条款不得有"待确认"。
